# Third-party assets

The SVG files in src/icons are copies of the corresponding files from the
official Lucide repository:

- search.svg: https://github.com/lucide-icons/lucide/blob/main/icons/search.svg
- settings.svg: https://github.com/lucide-icons/lucide/blob/main/icons/settings.svg
- heart.svg: https://github.com/lucide-icons/lucide/blob/main/icons/heart.svg

Lucide's upstream license file is included as LUCIDE-LICENSE.txt. It identifies
search as derived from Feather and licenses that icon under MIT. Settings and
heart are distributed under Lucide's ISC license. These example assets are
separate from the Semion library and are not bundled by it.
